# Nova Browser

A simple Bengali-friendly browser start page that can be hosted free with GitHub Pages.

## Publish on GitHub from your phone
1. Sign in at https://github.com
2. Tap **+** → **New repository**.
3. Name it `nova-browser`, choose **Public**, then create the repository.
4. Open the repository → **Add file** → **Create new file**.
5. Name the file `index.html`, paste the contents of `index.html` from this ZIP, then commit the file.
6. Open **Settings** → **Pages**.
7. Under **Build and deployment**, choose **Deploy from a branch**; select branch `main` and folder `/(root)`, then **Save**.
8. Wait a minute or two. Your site will appear at `https://YOUR-USERNAME.github.io/nova-browser/`.

## Important limitation
This is a browser-style start page, not a full standalone browser engine. Search results and websites open in a new tab. Many websites block being displayed inside another site's frame, so this static GitHub Pages app cannot embed every website like Chrome does.
